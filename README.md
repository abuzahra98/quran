# مراجع الحفظ — Hifz Reviewer

تطبيق ويب من ملف واحد لمراجعة حفظ القرآن بالتكرار المتباعد (SM-2) على صفحات مصحف المدينة (٦٠٤ صفحات).

## التشغيل
افتح `index.html` في أي متصفح. لا يحتاج إنترنت ولا سيرفر. التقدم يُحفظ في `localStorage` الخاص بالمتصفح.
(النسخة المنشورة على claude.ai تحفظ التقدم إضافياً في حسابك للمزامنة بين الأجهزة.)

## البنية
```
index.html              التطبيق المبني (ناتج البناء، لا تعدّله يدوياً)
src/app.template.html   القالب: HTML + CSS + JS للتطبيق كله
src/build.py            يدمج القالب + الخط + البيانات → index.html
data/hafs.json          المصدر الخام: نص مجمع الملك فهد (UthmanicHafs v3) بحدود الصفحات والأجزاء
data/build_qdata.py     يحوّل hafs.json → qdata.json
data/qdata.json         البيانات المضمّنة: {surahs, ayahs, rub}
fonts/UthmanicHafs-v-3.0.ttf  خط المصحف (مجمع الملك فهد)
```

## إعادة البناء بعد التعديل
```powershell
python data\build_qdata.py data\hafs.json data\qdata.json   # فقط إذا غيّرت البيانات
python src\build.py
```

## شكل بيانات الآية في qdata.json
`[السورة, رقم الآية, الصفحة, الجزء, النص العثماني مع علامات الوقف, النص الإملائي المجرد]`

## الجدولة (SM-2)
لكل صفحة سجل `{e, i, r, d, l, n, lp}`: عامل السهولة، الفترة بالأيام، مرات النجاح المتتالية، يوم الاستحقاق، آخر مراجعة، عدد المراجعات، مرات النسيان.
التقييم: نسيت=0، صعب=3، جيد=4، سهل=5. أول «جيد» → غداً ثم ٤ أيام ثم ×e. أول «سهل» → ٤ أيام ثم أسبوع.

## إهداء
